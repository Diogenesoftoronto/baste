# Baste × Graphite material studies

Four background families derived from Baste's existing atelier direction in
`PRODUCT.md` and `site/src/global.css`: warm pattern paper, ink, red basting
thread and blue tailor's chalk. The reserved reading area is the left 56%.

The originals are generated by Graphite, through real `graphite-editor-mcp`
stdio calls. The comparison sheets use Pillow for resizing and labels only.
The source documents, exact seeds, render hashes and exit metadata are kept
alongside the candidates so the assets can be regenerated.

## Materials

- **Flax linen:** quiet paper grain and repeated warp/weft, with a red edge seam.
- **Cutting room:** warm pattern stock, garment contours and seam allowances.
- **Chalk draft:** cool paper, blue pattern contours and measurement marks.
- **Ink selvedge:** warm charcoal cloth, woven structure and loose red stitching.

Five rounds per family progressively tune the grain and pattern opacity while
varying seeds and contour placement. Final selection is a subjective visual
review against the repository's weighted criteria, not a hosted judge score.

## Connection and reproduction

The connector is installed at `~/.local/share/graphite-editor-mcp`, with upstream
engine commit `d7ae6029e0c1818d81a13b0389ef1808496a715b` and the connector's
versioned node-metadata patch. It is registered with Codex as `graphite-editor`.
The study script itself opens the same server using the MCP SDK over stdio.

From the Baste project root:

```sh
rtk proxy node assets/output/graphite-baste-20261001/source/render.mjs inspect
rtk proxy node assets/output/graphite-baste-20261001/source/render.mjs draft
rtk proxy node assets/output/graphite-baste-20261001/source/render.mjs final
```

The first engine build on this machine needed `/usr/bin` ahead of the Guix
compiler utilities, and explicit GCC selection:

```sh
rtk proxy env PATH=/usr/bin:/home/diogenes/.nix-profile/bin:/bin CC=/usr/bin/gcc CXX=/usr/bin/g++ 'RUSTFLAGS=--cfg=web_sys_unstable_apis -Clinker=/usr/bin/gcc' CARGO_BUILD_JOBS=4 bash scripts/fetch-engine.sh
```

Run that last command inside the connector installation when rebuilding.
It is not needed for normal rendering after installation.

## Delivery boundaries

These are static, full-frame compositions. They are not certified as seamless
tiles. Place them using `background-size: cover`; crop-test against the actual
page before adoption. The dark material requires light text. PNG originals and
the legacy `.graphite` sources are preserved; current public-editor import
compatibility is unverified. No website styles are changed by this study.
