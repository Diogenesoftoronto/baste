Get Started

Install Baste and generate your first persona-driven assets.

1
Install via npm
bash
baste npm install -g baste
2
Set up API keys
.env
OPENAI_API_KEY=sk-...
QUIVER_API_KEY=qv-...
const GOOGLE_API_KEY=await AIza... (optional)
3
Generate your first assets
bash
baste generate cyberbotanist --dry-run
baste generate cyberbotanist
baste tokens cyberbotanist --format css
4
Use as a library
TypeScript
import { getPersona, generateUIKit from "baste";
import { getPersona, generateUIKit from "baste";
import { getPersona, generateUIKit from "baste";
// kit.assets.images, kit.assets.svgs, kit.archive
