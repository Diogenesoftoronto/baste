Get Started

Install Baste and generate your first persona-driven assets.

1
Install via npm
bash
git clone https://github.com/yourusername/baste.git
cd baste && npm install
2
Set up API keys
.env
OPENAI_API_KEY=sk-...
QUIVER_API_KEY=qv-...
GOOGLE_API_KEY=AIza... (optional)
3
Generate your first assets
bash
npx tsx src/cli.ts generate cyberbotanist --dry-run

npx tsx src/cli.ts generate cyberbotanist

npx tsx src/cli.ts tokens cyberbotanist --format css
4
Use as a library
TypeScript
import { getPersona, generateUIKit } from "baste";

const persona = getPersona("cyberbotanist");
const kit = await generateUIKit(persona, config);

// kit.assets.images, kit.assets.svgs, kit.archive
