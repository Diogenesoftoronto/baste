## Unresolved observations

- The live root, Studio and docs returned 200; /health returned static mode and /api/health returned 404. No Set-Cookie response header was present for those GETs; JavaScript can still set the language cookie.
- The source-level provider list is not a contractually verified processor list. Actual credentials, provider account options, regions and production registration remain unknown.
- Not Organic served review texts were read as context only (captured pages cd6d063cb15a50df and c33f4432eaa5e429 in the existing legal review evidence); both say Prepared for review, not yet effective. Operator assertions and retention figures from them were not transplanted as Baste facts.
- Baste not located in previously captured provider origin registry: bounded earlier evidence. A source PRODUCT_IDS declaration is not registration. No live registry or private user row was read here.
- Current local account code has narrower mechanisms than a complete hosted policy needs. It does not establish live provider approval, successful billing or a complete account-delete/export workflow.
- Generated asset licences, font licences and third-party source permissions must be considered individually. Source MIT wording does not establish universal asset clearance.
