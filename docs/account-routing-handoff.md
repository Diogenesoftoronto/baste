Confirm that this scope is approved for the limited account launch. No wallet data is fetched by the wrapper. A later full Studio account offering requires a separate scope/routes/processing review.

The existing Baste project has no durable storage. The new entry point refuses adopted-mode startup without a distinct `/app/data` mount. Do not store valid acceptance receipts on an ephemeral container and claim persistence across deployments. Sessions remain in memory and require a new sign-in after restart; accepted current-version receipts can survive only with an approved durable store.
